KHANAPINA WEBSITE

HOW TO VIEW:
1. Extract the ZIP file.
2. Open the khanapina_website folder.
3. Double-click index.html. It opens in your browser.
4. An internet connection is needed for the Tailwind CSS CDN.

HOW TO PUBLISH FREE WITH GITHUB PAGES:
1. Sign in at https://github.com and create a new public repository (example: khanapina).
2. Upload index.html and the complete images folder. Keep the folder structure unchanged.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. Your public website URL will appear in the Pages section.

BEFORE PUBLISHING:
- Add real restaurant address, phone number and opening hours in index.html.
- Confirm menu names and add actual prices if desired.
- The supplied five photographs are already included in the images folder.
